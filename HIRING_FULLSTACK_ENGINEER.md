# Full-Stack Engineer - Curb Platform

## About Curb

Curb is revolutionizing the used car market by connecting consumers directly to wholesale dealer inventory through transparent 3-day auctions. We cut out the middleman markup while ensuring buyer protection through professional inspections, repair guarantees, and escrow-backed transactions.

We're launching in Southern California and building the infrastructure to scale nationally.

## The Role

We're looking for a **senior full-stack engineer** to be our first technical hire and take our functional prototype to production launch. You'll own the entire technical architecture and build the core marketplace platform from the ground up.

**Type:** Full-time or Contract (6-12 months with potential for permanent)
**Location:** Remote (US-based preferred) or Los Angeles area
**Compensation:** $120k-150k salary OR $75-125/hr contract (depending on experience)
**Equity:** 1-3% for full-time hire

## What You'll Build

### Phase 1: Core MVP (Months 1-3)
- **User authentication system** - Buyer and dealer account creation, verification, role-based access
- **Dealer dashboard** - Vehicle listing flow, inspection upload, auction management
- **Auction system** - Real-time bidding, countdown timers, bid notifications
- **Database architecture** - User data, vehicle inventory, bids, transactions
- **Admin panel backend** - Platform monitoring, user management, dispute resolution

### Phase 2: Transactions & Scale (Months 4-6)
- **Payment integration** - Escrow.com API integration, payment processing
- **Notification system** - Email/SMS for bids, auction wins, status updates
- **Search & filtering** - Vehicle discovery, saved searches, alerts
- **Rating system** - Dealer ratings, buyer feedback, dispute workflows
- **Performance optimization** - Caching, CDN, database indexing

### Phase 3: Advanced Features (Months 6+)
- **Mobile optimization** or native app
- **AI integration** - VIN decoding, pricing suggestions, fraud detection
- **Analytics dashboard** - Platform metrics, dealer performance, revenue tracking
- **Advanced auction features** - Reserve pricing, buy-it-now, proxy bidding

## Tech Stack

### Current (Prototype)
- **Frontend:** Next.js 16 (App Router), TypeScript, Tailwind CSS
- **Hosting:** Vercel
- **Version Control:** Git/GitHub

### You'll Add
- **Backend:** Node.js/Express, Next.js API routes, or your preferred framework
- **Database:** PostgreSQL (recommended) or MongoDB
- **Real-time:** WebSockets (Socket.io) or Pusher
- **Payments:** Stripe + Escrow.com API
- **Auth:** NextAuth.js, Auth0, or Supabase
- **Email:** SendGrid or Resend
- **File Storage:** AWS S3 or Cloudinary
- **Monitoring:** Sentry, LogRocket, Vercel Analytics

*We're open to your recommendations on the best tools for the job.*
